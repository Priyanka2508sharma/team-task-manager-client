# Team Task Manager

A full-stack MERN application for managing projects and tasks.

## Live Demo

Frontend:
https://team-task-manager-client-pubs-kns65bvwy.vercel.app

Backend:
https://team-task-manager-production-0f6b.up.railway.app

## Features

- User Signup/Login
- JWT Authentication
- Create Tasks
- Dashboard
- MongoDB Integration
- Responsive UI

## Tech Stack

Frontend:
- React.js
- Axios
- React Router DOM

Backend:
- Node.js
- Express.js
- MongoDB
- JWT
- bcryptjs
